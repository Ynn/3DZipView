# 3DZipView

3DZipView is very simple (yet another) browser-based PWA for inspecting ZIP packages and 3D assets without uploading data. It previews FBX, GLB, GLTF, and OBJ files, resolves sidecar textures, supports mounted folders in Chromium browsers, offers lit, unlit, and wireframe modes.

## Stack

- Vite
- Three.js
- JSZip
- vite-plugin-pwa
